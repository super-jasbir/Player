# Quiz assets

Artwork for the quiz flow (registered in pubspec as `assets/images/quiz/`).
Paths are referenced from `lib/quiz/widgets/quiz_chrome.dart` (`QuizAssets`).

- `ic_quiz_bg.png` — classroom background (sharp on the intro, blurred behind
  the glass cards on the other screens).
- `ic_teacher.png` — the quiz host character on the intro screen.
- `ic_congratulation_bg.png` — the gold starburst badge behind the score on the
  result screen.
- `ic_city_blur.png` — spare blurred city backdrop (not currently referenced).
